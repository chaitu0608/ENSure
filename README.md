# ENSure

ENSure helps a team publish a static website through ENSv2 and lets visitors check that the current site matches the release its owner approved.

The first version uses GitHub Actions to build, Pinata to pin static files to IPFS, and ENSv2 to control preview and production names.

Arkiv and Swarm are later integrations.
